This is a set of scripts to search for DNA repair genes in bacteria and archaea.

#### Requirements
- Having *hmmer* installed
- Having annotated protein sequences (.faa)

#### Scripts
**1. search_dna_repair_hmms.sh:** searches for DNA repair genes using hmm for bacteria or archaea

**2. summarize_hmmsearch.py:** summarizes the main statistics of the search

**3. presence_absence.py:** creates a presence-absence table of genes based on search filters
